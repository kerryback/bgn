# File Requirements for Refactor2

## Required Data Files

### Jstar.csv

**Location:** `Refactor2/Jstar.csv`

**Purpose:** Contains interpolation data for the BGN model's growth option valuation (J*).

**Format:**
```csv
r,J
-0.018743891229990255,167.19220771452845
-0.018618995737005553,166.02605989175836
...
```

**Columns:**
- `r`: Interest rate values
- `J`: Corresponding J* (value of growth options) values

**Used by:** `panel_functions.py` (BGN model) when computing asset prices

**Size:** ~16 KB (500 rows)

**Already included:** ✓ This file is included in the Refactor2 directory

## Why Jstar.csv is Needed

The BGN (Bansal-Gallant-Navarro) model values firms' growth options using a function J*(r) that depends on the interest rate. This function is computed numerically and the results are stored in `Jstar.csv` for fast interpolation during simulation.

From `panel_functions.py` (lines 14-16):
```python
# Jstar = value of growth options
approx = pd.read_csv("Jstar.csv")
Jstar = interpolate.interp1d(approx.r, approx.J, fill_value="extrapolate")
```

The simulation then uses `Jstar(r[t])` to compute the value of growth options at each time period.

## File Locations

The code imports from the parent `Code` directory, so `Jstar.csv` must be present in:

1. **Primary location:** `Code/Refactor2/Jstar.csv` ✓
   - Used when running from Refactor2 directory
   - Working directory is `Code/Refactor2`

2. **Fallback location:** `Code/Jstar.csv` ✓
   - Used if running from Code directory
   - Working directory is `Code`

Both locations now have the file copied.

## How the File Was Created

`Jstar.csv` was originally generated by solving a numerical optimization problem for the BGN model. The optimization computes the value function for firms with growth options at different interest rate levels.

The file is static (doesn't change across simulations) and can be reused.

## If File is Missing

If you see an error like:
```
FileNotFoundError: [Errno 2] No such file or directory: 'Jstar.csv'
```

**Solution:**
1. Ensure you're running from the `Refactor2` directory
2. Verify `Jstar.csv` exists in `Refactor2/` directory
3. If missing, copy from `BGN/Code/Jstar.csv` to `Refactor2/`

**Quick fix:**
```bash
cd Refactor2
# If file is missing, copy it:
cp ../BGN/Code/Jstar.csv .
```
